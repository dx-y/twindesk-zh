## 二、改了什么

上游 3.x 已把界面文案集中到 `shared/lang/<code>.js`，官方 `zh-CN.js` 2279 条全中文。剩余英文来自两处：

1. **代码里写死的字面量**：不经过 `tr()`，直接拼进界面。共 133 处，分布在 45 个文件
   （`shared/ui-web.js`、`shared/reclaim.js`、`shared/iossign.js`、`windows/ipc.js`、`windows/screen.js`、
   `android/app/src/main/assets/web/remote.js` 等），改为中文。
2. **`tr()` 用了但词表没收录的键**：静态扫描出 1031 个，去重后 999 条。全部译出，落到独立补充表
   `zh-extra.js`（同源三份：`shared/lang/`、`web/lang/`、`android/app/src/main/assets/web/`）。

接入方式：

| 位置 | 改动 |
| --- | --- |
| `shared/i18n.js` | 查询顺序改为「当前语言词表 → 中文补充表（仅 zh-CN）→ 英文词表 → 原键」；Node 侧 `require`，浏览器侧读 `globalThis.TwinDeskZhExtra` |
| `shared/lang/pick.js` | `?language=zh-CN` 时先注入 `zh-extra.js`，其他语言不加载 |
| `web/app.js`、`web/lang/pick.js` | 网页端同样处理 |
| `android-web` 三页（remote / viewer / audio） | 业务脚本前插入 `<script src="zh-extra.js">`，随 `/td/` 路由下发 |
| `shared/deck-model.js` | 卡片面板瓦片标签与分区名改为中文 |
| `windows/installer/build.js` | 新增 `TWINDESK_SKIP_HELPER_BUILD=1` 开关：复用上游已编译 helper（无 Windows SDK 的机器需要） |

## 三、校验

- 999 条键全部译出，其中 195 条含 `{占位符}`，占位符一致性校验通过。
- 用打包产物内的 `shared/i18n.js` 与真实词表在 Node 中全量回归：999 条中 992 条输出中文；
  7 条按规则保留原文——`AirPlay`、`AirPlay · {name}`、`Esc`、`TwinDesk`、`TwinDesk Web`、`TwinDesk {version}`、`Windows`。
- 英文环境回归：`en.t('Save')` 仍返回 `Save`，未被中文补充表污染。
- 覆盖安装后逐页抓取 492 条界面文字：仅余 6 处英文，均为产品名与系统信息；iPhone 页中英混排已消除。

## 四、安装与抽查

1. 运行 `TwinDesk-Setup-3.2.1-zh-CN.exe`，通过 UAC 后按向导安装。
2. 未签名，SmartScreen 提示时选「更多信息 → 仍要运行」。
3. 重点抽查：设置页各分类、卡片面板与瓦片标签、投屏/文件传输/剪贴板提示、各类报错弹窗。
4. 手机端：电脑端开启网页共享，手机浏览器访问 `https://<电脑名>.local:8443/td/`，遥控页、查看器页、音频页文案应为中文。

## 五、构建环境

- npm 与 Electron 二进制走 `registry.npmmirror.com`、npmmirror 镜像；`CSC_IDENTITY_AUTO_DISCOVERY=false` 免签。
- 原生组件（`windows-helper/bin`、`ios-signer/bin`、预编译 APK）沿用官方 3.2.1 产物。
